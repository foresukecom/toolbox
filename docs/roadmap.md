# 機能追加ロードマップ

Web 開発者向けに追加したいツールの一覧。既存33ツールと重複しないものを、利用頻度・検索需要・実装コストで優先度付けしている。

**共通コンセプト**: すべてブラウザ内で処理し、入力データを外部へ送信しない（JWT・差分など機密を貼りがちなツールの信頼性を担保する）。

## ステータス凡例

| 記号 | 意味 |
|---|---|
| 📝 | 計画済み（実装プランあり） |
| 💡 | アイデア段階 |
| ✅ | 実装済み |

## 優先度：高（Wave 1 / 並列実装対象）

実装プラン: [docs/plans/dev-tools/](plans/dev-tools/00_overview.md)

| # | ツール | 概要 | 追加依存 | 状態 |
|---|---|---|---|---|
| 1 | JWT デコーダー | header / payload を表示、`exp` / `iat` を JST 表示、期限切れ判定、HS 系署名検証 | なし | 📝 |
| 2 | エンコード/デコード | Base64（UTF-8 / URL-safe）・URL・HTML エンティティ、画像→Data URI | なし | 📝 |
| 3 | cron 式解説 | 日本語の説明と次回実行日時一覧（JST / UTC 切替） | `cronstrue`, `cron-parser` | 📝 |
| 4 | カラー変換 | HEX / RGB / HSL / OKLCH 相互変換、WCAG コントラスト比チェック | なし | 📝 |
| 5 | テキスト差分 | 行 / 単語 / 文字単位の差分表示、空白・大文字小文字無視 | `diff` | 📝 |
| 6 | YAML / JSON / TOML 変換 | 3形式の相互変換、パースエラー位置表示 | `yaml`, `smol-toml` | 📝 |

## 優先度：中（Wave 2 候補）

| ツール | 概要 | メモ | 状態 |
|---|---|---|---|
| curl → コード変換 | curl コマンドを fetch / axios / Go に変換 | パーサ自作 or ライブラリ調査 | 💡 |
| HTTP ステータス / ヘッダー辞典 | 日本語解説付きリファレンス | 静的データ中心、SEO に強い | 💡 |
| chmod 計算機 | `755` ⇔ `rwxr-xr-x` ⇔ チェックボックス | 依存なし・小規模 | 💡 |
| CIDR / サブネット計算機 | ネットワーク範囲・ホスト数・マスク | 既存 `ip-info` と連携可 | 💡 |
| QR コード生成 | テキスト / URL / Wi-Fi 設定から生成 | `qrcode` 等 | 💡 |
| 画像圧縮・リサイズ・形式変換 | WebP / AVIF 変換 | 既存 EXIF削除 の延長 | 💡 |
| OGP プレビュー | SNS カード表示の確認 | 取得は Netlify Functions (Go) | 💡 |
| SQL 整形 | SQL フォーマッター | `sql-formatter` | 💡 |
| Markdown プレビュー | Markdown ⇔ HTML | `marked` 等 | 💡 |
| ダミーデータ生成 | 日本人名・住所・電話番号・メール | 既存ランダム文字列生成の発展 | 💡 |

## 横断的な改善アイデア

- **URL パラメータで入力状態を共有**: 「この JWT / cron 式を見て」とチームで回覧しやすくする
- **カテゴリ整理**: Wave 1 完了後、「開発者ツール」カテゴリの細分化（エンコード / データ形式 / ネットワーク）を検討
