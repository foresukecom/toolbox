# Step 03: CSV整形（Issue #15）

> 着手前に [00_overview.md](00_overview.md) の「全エージェント共通ルール」を読むこと。

## 担当

| 項目 | 値 |
|---|---|
| 編集ファイル | `src/views/CsvFormatter.vue`（これのみ） |
| ブランチ | `feat/wave2-csv` |
| 追加依存 | `papaparse`（Step 01 で導入済み。追加インストールしない） |

## 目的

Issue の要望は「Markdown 形式の表にしたり、色を変えたり」。CSV を読みやすく整形・変換する。

## 機能要件

### 必須

1. **入力**: テキストエリア。CSV ファイルの選択（`FileReader` で読み込み、UTF-8）にも対応する
2. **読み取り設定**
   - 区切り文字: 自動 / カンマ / タブ / セミコロン / パイプ
   - 「1行目を見出しにする」（初期値 ON）
   - 先頭の BOM は除去する
   - 行ごとに列数が違う場合は、最大列数に合わせて空セルで埋める
3. **表示（色分け）**: 列ごとに色を変えた表で表示する（Rainbow CSV のイメージ）
   - 色は列番号ごとに循環する6〜8色。ライトモードで読みやすいコントラストにする
   - 見出し行は太字
   - 行数・列数を表示する
4. **出力（タブで切り替え、それぞれ `CopyButton` 付き）**
   - **Markdown の表**: セル内の `|` は `\|`、改行は `<br>` に置き換える。列ごとの寄せ（左 / 中央 / 右）を選べる。「数値だけの列は自動で右寄せ」オプション
   - **整列テキスト**: 列幅を揃えた等幅テキスト。**全角文字を幅2として数える**（`Intl.Segmenter` で書記素単位に分け、East Asian Width の全角・広い文字を2とする簡易判定でよい）
   - **JSON**: 見出しありならオブジェクトの配列、なしなら配列の配列
   - **CSV（正規化）**: 区切り文字を選んで出力し直す。必要なセルだけクォートする
5. **エラー表示**: Papa Parse のエラー（クォートの閉じ忘れなど）を行番号付きで表示する。画面は落とさない
6. **大きな入力**: 表示は先頭 500 行までにして「残り N 行は省略」と出す。出力（Markdown など）は全行を対象にする

## 動作確認

入力例:

```csv
名前,年齢,メモ
山田,30,"東京, 日本"
Smith,4,"改行
あり"
佐藤,,a|b
```

| 確認 | 期待結果 |
|---|---|
| 上の CSV（見出し ON） | 3行 × 3列。`東京, 日本` が1つのセルになる |
| Markdown 出力 | 1行目が `| 名前 | 年齢 | メモ |`、区切り行あり。`改行<br>あり`、`a\|b` |
| 「数値列を右寄せ」ON | 年齢列の区切りが `---:` |
| 整列テキスト | `名前` と `Smith` の列の右端が揃う（全角を幅2で計算） |
| JSON 出力 | `[{"名前":"山田","年齢":"30","メモ":"東京, 日本"}, ...]` |
| タブ区切りのデータ（自動判定） | 正しく列に分かれる |
| 列数がばらばらの CSV | 足りないセルが空で埋まる |
| `a,"b` | エラーが行番号付きで表示され、画面は落ちない |
| 先頭に BOM 付きのファイル | 1列目の見出しに BOM が混ざらない |
| 見出し OFF | 1行目もデータとして扱われ、JSON は配列の配列 |
