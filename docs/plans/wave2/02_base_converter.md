# Step 02: 基数変換（Issue #36）

> 着手前に [00_overview.md](00_overview.md) の「全エージェント共通ルール」を読むこと。

## 担当

| 項目 | 値 |
|---|---|
| 編集ファイル | `src/views/BaseConverter.vue`（これのみ） |
| ブランチ | `feat/wave2-base` |
| 追加依存 | なし（`BigInt` を使う） |

## 機能要件

### 必須

1. **入力**: テキスト入力1つ + 入力の基数の選択（自動 / 2 / 8 / 10 / 16）。初期値は `255`、自動
   - 自動: `0b` / `0o` / `0x` の接頭辞で判定し、なければ10進数として扱う
   - 区切り文字の `_`、`,`、空白は無視する（例: `1_000_000`、`ff ff`）
   - 先頭の `-` で負の数を扱う
2. **出力**: 2 / 8 / 10 / 16 進数を並べて表示し、それぞれに `CopyButton` を付ける
   - 16進数は小文字と大文字を切り替えられる
   - 「接頭辞を付ける」オプション（`0b` / `0o` / `0x`）
   - 「桁区切り」オプション（2進数と16進数は4桁ごとに空白、10進数は3桁ごとに `,`）
3. **任意の桁数**: `BigInt` で計算し、`Number` の精度（2^53）を超えても正しく変換する
4. **ビット数の表示**: 絶対値を表すのに必要なビット数
5. **2の補数表示**: 8 / 16 / 32 / 64 ビットを選び、その幅での2の補数（2進数・16進数）を表示する。範囲外の値は「範囲外」と表示する
6. **エラー表示**: その基数で使えない文字があれば、画面を落とさずに「2進数として不正な文字があります: 2」のように表示する

### 任意

7. 各ビットをクリックで反転できるビット表示（32ビットまで）

## 動作確認

| 入力（基数） | 期待結果 |
|---|---|
| `255`（自動） | 2進 `11111111` / 8進 `377` / 16進 `ff` |
| `0x1F`（自動） | 10進 `31` |
| `0b1010`（自動） | 10進 `10` |
| `0o777`（自動） | 10進 `511` |
| `ff`（16） | 10進 `255` |
| `12345678901234567890`（10） | 16進 `ab54a98ceb1f0ad2`、8進 `1255245230635307605322`、ビット数 64 |
| `-10`（10） | 2進 `-1010` |
| `-1`、2の補数 8ビット | `11111111` / `ff` |
| `-2`、2の補数 16ビット | 16進 `fffe` |
| `256`、2の補数 8ビット | 「範囲外」 |
| `1_000_000`（10） | 16進 `f4240` |
| `0b102`（自動） | エラー表示 |
| `xyz`（16） | エラー表示 |
| 空文字 | 何も表示しない |
| 桁区切り ON で `65535` | 2進 `1111 1111 1111 1111`、10進 `65,535` |
