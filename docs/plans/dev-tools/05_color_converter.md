# Step 05: カラー変換

> 着手前に [00_overview.md](00_overview.md) の「全エージェント共通ルール」を読むこと。

## 担当

| 項目 | 値 |
|---|---|
| 編集ファイル | `src/views/ColorConverter.vue`（これのみ） |
| ブランチ | `feat/dev-tools-color` |
| 追加依存 | なし（変換式を自前で実装する） |

## 目的

CSS で使う色表記を相互変換し、文字色と背景色のコントラスト比（WCAG 2.x）を確認できるようにする。

## 機能要件

### 必須

1. **入力**: テキスト入力 1つ + `<input type="color">`（双方向に同期）。初期値 `#16a085`
2. **受け付ける形式**
   - HEX: `#rgb` / `#rgba` / `#rrggbb` / `#rrggbbaa`（`#` なしも可）
   - `rgb(r g b)` / `rgb(r, g, b)` / `rgba(...)`
   - `hsl(h s% l%)` / `hsl(h, s%, l%)`
   - `oklch(L C H)`（L は `%` または 0〜1）
3. **出力**（それぞれ `CopyButton` 付き）
   - HEX（`#rrggbb`、アルファが 1 未満なら `#rrggbbaa`）
   - `rgb(r g b)` / `rgb(r g b / a)`
   - `hsl(h s% l%)`
   - `oklch(L% C H)`（L は小数1桁、C は小数4桁、H は小数2桁）
4. **プレビュー**: 色見本の四角形
5. **コントラスト比チェッカー**
   - 文字色 / 背景色 の2入力（初期値: 文字色=上で入力した色、背景色=`#ffffff`）
   - 比率を `4.48 : 1` のように小数2桁で表示
   - 判定表: AA 通常文字（4.5）/ AA 大きな文字（3.0）/ AAA 通常文字（7.0）/ AAA 大きな文字（4.5）を ✓ / ✗ で表示
   - 実際の文字色と背景色でサンプル文を表示
6. **エラー表示**: 解釈できない入力は画面を落とさずメッセージを出す

### 任意（余裕があれば）

7. 名前付き色（`red`, `rebeccapurple` など）の入力対応
8. sRGB の範囲外になる OKLCH 入力の警告（クリップして表示）

## 変換式メモ

- **sRGB ↔ 線形 sRGB**: `c <= 0.04045 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4`（逆変換も同様）
- **相対輝度（WCAG）**: `L = 0.2126 R + 0.7152 G + 0.0722 B`（線形値）
- **コントラスト比**: `(L1 + 0.05) / (L2 + 0.05)`（L1 が明るい方）
- **OKLab / OKLCH**: Björn Ottosson の定義（https://bottosson.github.io/posts/oklab/ ）の行列を使う。線形 sRGB → LMS → 立方根 → OKLab → 極座標（`C = sqrt(a² + b²)`、`H = atan2(b, a)` を度に変換して 0〜360 に正規化）
- 無彩色（C ≒ 0）のときの色相は `0` と表示する

## 動作確認

| 入力 | 期待結果 |
|---|---|
| `#ff0000` | `rgb(255 0 0)` / `hsl(0 100% 50%)` / `oklch(62.8% 0.2577 29.23)` |
| `#f00` | 上と同じ |
| `rgb(0, 128, 255)` | `#0080ff` |
| `hsl(120 100% 25%)` | `#008000` |
| `#00000080` | `rgb(0 0 0 / 0.5)` 前後（アルファ 128/255 ≒ 0.502） |
| `oklch(62.8% 0.2577 29.23)` | `#ff0000`（丸め誤差で ±1 は許容） |
| `#ffffff` と `#000000` | `21.00 : 1`、すべて ✓ |
| 文字 `#777777` / 背景 `#ffffff` | `4.48 : 1`、AA 通常 ✗ / AA 大 ✓ |
| `#ffffff` | oklch の H は `0`（NaN にならない） |
| `xyz` | エラー表示、画面は落ちない |
| カラーピッカーで色を選ぶ | テキスト入力と全出力が更新される |
